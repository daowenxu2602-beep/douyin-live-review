## 开播前24小时准备清单

### T-24h（前一天）

- [ ] 确认选品清单和排品表已定稿
- [ ] 确认每个品的库存充足（含备货buffer）
- [ ] 确认每个品的卖点卡片已更新（价格、机制、赠品信息）
- [ ] 确认直播间灯光/背景布置完成
- [ ] 确认预热短视频已发布/计划发布时间
- [ ] 如有投放计划，确认千川计划已搭建并审核通过

### T-4h（开播前4小时）

- [ ] 所有商品已在抖店后台检查链接有效性
- [ ] 确认福袋/优惠券已设置好（金额、数量、发放时机）
- [ ] 检查直播中控台商品列表顺序与排品表一致
- [ ] 确认主播到岗，做话术过堂（至少过一遍核心品的讲解）
- [ ] 检查设备状态（手机/相机、麦克风、灯光、网络）

### T-30min（开播前30分钟）

- [ ] 开启直播测试画面，确认画面/声音/灯光正常
- [ ] 确认所有商品已上架到直播间商品列表
- [ ] 确认优惠券/福袋已关联到对应商品
- [ ] 场控与主播最后确认本场重点品和关键节奏点
- [ ] 确认备用设备就位（备用手机、备用网络）
- [ ] 中控台刷新确认，一切就绪后正式开播

## 选品排品指南

### 排品基本逻辑

一场直播的排品不是随意排列，而是遵循**流量节奏与商品属性的匹配逻辑**：

| 直播时段 | 排品策略 | 目的 | 品类选择 |
|----------|----------|------|----------|
| 开播0-30min | 引流款开场 | 快速成交、拉互动、给系统正向信号 | 低客单价、高性价比、大众认知度高的品 |
| 30min-2h | 核心利润款 | 贡献主要GMV和利润 | 中高客单价、毛利空间大、有讲解深度的品 |
| 中间穿插 | 爆款返场 | 维持在线人数、拉新客转化 | 前期转化最好的品重复讲 |
| 中后段 | 新品测试 | 测新品反应、收集数据 | 新上架品、潜力品 |
| 收尾前 | 清仓/福利款 | 最后冲刺GMV、清理库存 | 尾货、临期品、福利组合装 |

### 排品注意事项

- **引流款不宜超过3个**，否则拉低了整体客单价和UV价值
- **利润款之间穿插福利款**，避免观众审美疲劳和价格锚点过高
- **爆款返场间隔≥40分钟**，同一品短期内重复讲会降低转化
- **新品测试放在流量稳定期**，不要在流量低谷或高峰期测品
- **每个品讲解时长建议**：引流款3-5分钟，利润款8-15分钟，爆款返场5-8分钟

### 场控在排品环节的角色

场控虽然不主导选品决策，但需要：
1. 理解排品逻辑，知道每个品在排品表中的"角色"（引流/利润/爆款/清仓）
2. 记住每个品的核心卖点、价格机制、库存数量
3. 在直播中根据实时数据自主调整切品时机（如利润款转化差时提前切到爆款返场）
4. 在复盘中反馈排品执行效果，为运营调整排品策略提供依据

## 脚本话术准备

### 话术结构框架

一个完整的单品讲解话术应包含以下环节：

**1. 开场钩子（10-30秒）**
- 用痛点/场景/反差/悬念抓住注意力
- 例："你们是不是也遇到过xxx的问题？今天这个品就是来解决这个问题的"

**2. 产品讲解（3-8分钟）**
- 卖点不超过3个，重点讲1个核心卖点
- 用"场景化"而非"参数化"的方式讲（说"用完皮肤水润一整天"而非"含透明质酸5%）
- 配合实物展示、对比演示

**3. 价格锚定（1-2分钟）**
- 先报日常价/专柜价/原价
- 再揭晓直播间专属价/机制
- 强调限时/限量/福利感

**4. 催单逼单（2-5分钟）**
- 制造紧迫感（"还剩最后50单"、"这个价格只有今天"）
- 提供决策辅助（"不知道选哪个就选套餐B，性价比最高"）
- 反复确认购买入口和操作步骤

**5. 逼单后承接（30秒-1分钟）**
- 对已购买的用户做确认动作（"拍了的扣1"、"拍到的恭喜"）
- 自然过渡到下一个品

### 场控与话术的配合

场控在话术执行中的职责：
- **递品时机把控**：主播讲到哪个节点，场控递上对应实物/道具
- **话术提示**：通过提词器/耳麦提醒主播遗漏的关键信息（价格、库存、赠品）
- **催单配合**：主播逼单时，场控同步在中控台操作（改库存制造紧迫感、发优惠券）
- **数据驱动话术调整**：如果某品讲解5分钟后转化率持续低迷，场控需判断是继续讲还是切品

### 常见话术问题及场控应对

| 问题表现 | 可能原因 | 场控应对动作 |
|----------|----------|--------------|
| 主播讲完价格但没人下单 | 价格锚定不够/紧迫感不足 | 提示主播加强逼单话术，同步发优惠券刺激 |
| 在线人数持续下降 | 讲解时间过长/内容枯燥 | 提示主播加快节奏或切到下一个品 |
| 弹幕有人质疑价格 | 价格机制不清楚/对比不够 | 提示主播做价格拆解或对比演示 |
| 主播忘词/卡壳 | 话术不熟/状态不好 | 通过耳麦提示关键词，必要时递上话术卡片 |

## 设备与环境检查

### 设备检查清单

**画面设备（手机/相机）：**
- [ ] 画面清晰度检查（分辨率≥1080P）
- [ ] 画面构图检查（商品展示区域、主播位置、背景整洁度）
- [ ] 无画面卡顿/花屏/延迟
- [ ] 备用拍摄设备已就位并测试通过

**声音设备：**
- [ ] 麦克风收音清晰，无杂音/回声/断续
- [ ] 主播移动时声音稳定（无线麦信号范围测试）
- [ ] 背景音乐音量适中（不盖过人声）
- [ ] 备用麦克风已就位

**网络设备：**
- [ ] 上传带宽≥10Mbps（可用speedtest测试）
- [ ] 有线网络优先，无线作为备用
- [ ] 4G/5G热点已准备作为应急网络

**灯光设备：**
- [ ] 主光、辅光、轮廓光位置和亮度调整到位
- [ ] 无过曝/过暗区域
- [ ] 色温统一（建议5500K左右，自然白光）
- [ ] 商品展示区有独立补光

### 环境检查

- [ ] 直播间背景整洁，无杂乱物品
- [ ] 商品陈列区有序，每个品有固定摆放位置
- [ ] 温度适宜（主播长时间直播不会过热/过冷）
- [ ] 无外部噪音干扰（装修、交通等）

## 预热与流量准备

### 直播前预热动作

**短视频预热（T-24h ~ T-2h）：**
- 发布1-3条预热短视频，预告直播时间和核心福利品
- 视频内容：产品种草+直播福利预告+开播时间提醒
- 发布时间参考粉丝活跃时段（通常晚上7-10点活跃度最高）

**粉丝群/私域预热（T-12h ~ T-1h）：**
- 在粉丝群/朋友圈发布直播预告
- 预告核心品和机制，制造期待感
- 可以设置"到直播间领专属福利"的引导

**千川投放预热（如有投放计划）：**
- 开播前1-2小时开启预热计划，为直播间蓄水
- 定向人群：直播间粉丝相似人群+品类兴趣人群
- 预热预算通常占总预算的10-20%

### 开播冲量策略

开播前30分钟是获取系统推荐流量的关键窗口期。系统会根据开播初期的数据表现判断直播间质量，决定后续推荐量级。

**场控需要配合的开播冲量动作：**
1. 开播即放出引流款，快速产生成交数据
2. 前5分钟密集发福袋/优惠券，拉高互动率
3. 主播话术节奏要快，前15分钟不做过长讲解
4. 如果有投放计划，开播即加大投放力度（系统会根据实时在线人数调整展现）
5. 场控实时监控在线人数增速，如增速低于预期，及时提示主播加快节奏或切到福利品

## 场控专属准备事项

场控在开播前除了配合上述准备工作，还需要独立完成以下准备：

### 数据准备
- [ ] 记住本场直播目标GMV，做到心中有数
- [ ] 回顾上一场同时间段的直播数据（在线人数峰值、GMV、转化率），作为本场对比基准
- [ ] 确认罗盘大屏已打开并刷新正常

### 工具准备
- [ ] 计算器/Excel准备好（用于实时计算UV价值、转化率等）
- [ ] 排品表打印或投屏到工作位（方便随时查看）
- [ ] 场控记录表准备好（用于记录关键事件、切品时间、异常情况）
- [ ] 耳麦/对讲设备测试正常

### 沟通准备
- [ ] 与主播确认本场重点品和关键节奏点
- [ ] 与运营确认本场特殊安排（如有大额优惠券、特殊活动等）
- [ ] 与中控确认分工（谁负责发福袋、谁负责改库存、谁负责监控弹幕）
- [ ] 如有投放，与投放师确认开播投放计划和预算
