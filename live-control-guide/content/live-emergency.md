## 流量异常处理

### 流量暴跌（在线人数短时间内急降）

**判断标准：** 5分钟内在线人数下降超过30%，且无恢复迹象。

**排查顺序：**
1. 先查是否是自然波动（直播中流量本身有节奏性起伏，3-5分钟的小幅波动属正常）
2. 查罗盘大屏"流量来源"模块，看哪个渠道掉量最严重
3. 查是否有违规警告（直播间是否触发了平台风控限流）

**应对动作：**

| 下跌渠道 | 可能原因 | 场控动作 |
|----------|----------|----------|
| 推荐feed下降 | 内容互动数据下滑（停留、互动、转化） | 提示主播切换福利款+发福袋拉升互动数据 |
| 直播广场下降 | 直播间封面/标题吸引力不足或时段竞争加剧 | 无法实时改封面，用话术引导观众停留 |
| 付费流量下降 | 千川计划消耗放缓或预算耗尽 | 通知投放师加大投放或调整出价 |
| 关注tab下降 | 粉丝触达率降低（非活跃时段） | 发粉丝专属优惠券，引导关注 |

**通用救场动作（按优先级）：**
1. 切换到转化最好的爆款返场，用高转化数据拉系统推荐
2. 发大额福袋/限时优惠券，制造互动高峰
3. 提示主播加快话术节奏，用钩子话术拉停留
4. 如果有投放预算，通知投放师加大投放补量
5. 如果以上均无效，考虑做"二次开播"（下播后立即重开，利用开播冲量机制）

### 流量不增长（平销期在线人数停滞）

**判断标准：** 在线人数持续15分钟以上无明显增长，处于平台期。

**应对动作：**
- 切换到引流款，用低价高频成交拉系统推荐
- 发福袋（设置需要关注直播间才能参与），拉新粉
- 提示主播做互动引导（"想要的扣1"、"觉得好的扣666"）
- 检查是否到了自然流量低谷时段（如凌晨2-5点），如果是则属正常现象
- 考虑提前切到下一个排品环节，避免节奏拖沓

### 流量异常暴涨

**判断标准：** 在线人数短时间内异常增长（如5分钟翻倍）。

**判断是否好事：** 不一定是好事，要看流量质量。

**应对动作：**
- 立即查看流量来源，确认是自然推荐还是被引流（如被大V提及、上热门）
- 如果是自然推荐，抓住机会切到核心利润款，用高转化承接流量
- 如果是被引流（可能进来大量非目标人群），保持当前排品节奏，观察转化率变化
- 通知运营和投放师，评估是否需要同步加大投放
- 提醒主播注意节奏，不要因为人数涨了就打乱既定排品

## 转化异常处理

### 转化率突然下降

**判断标准：** 同一品的讲解时长内，商品点击率和成交转化率明显低于预期或前期水平。

**排查方向：**

| 可能原因 | 判断方式 | 应对动作 |
|----------|----------|----------|
| 话术问题 | 主播没有讲清卖点/价格机制 | 提示主播补充价格拆解或对比演示 |
| 价格偏高 | 弹幕有人觉得贵/犹豫 | 提示主播做价格锚定或发限时优惠券 |
| 商品讲解时间过长 | 在线人数持续下降 | 提示主播进入逼单环节或切品 |
| 商品本身问题 | 退款率/差评高 | 记录数据，复盘时提出淘汰建议 |
| 流量不精准 | 大量非目标人群进入 | 查看流量来源，通知投放师调整定向 |

### 核心品转化不达标

**判断标准：** 核心利润款的成交件数/GMV明显低于目标。

**应对动作：**
1. 先判断是流量问题还是转化问题（有流量但不转化 vs 流量就不够）
2. 如果是转化问题：检查主播话术是否到位、价格机制是否清晰
3. 尝试追加促销手段：限时优惠券、买赠、组合套餐
4. 如果多次尝试后仍不转化，记录数据在复盘时重点分析
5. 不要在一个品上死磕，及时切到下一个品保住整体节奏

### UV价值过低

**判断标准：** UV价值（GMV/在线人数）明显低于同品类行业水平。

**参考基准（因品类差异较大，仅作参考）：**
- 服装鞋包类：UV价值 2-5元
- 美妆护肤类：UV价值 3-8元
- 食品饮料类：UV价值 1-3元
- 家电数码类：UV价值 5-15元
- 珠宝饰品类：UV价值 10-30元

**应对动作：**
- 检查是否引流款占比过高拉低了整体客单价
- 提示主播增加利润款/高客单价品的讲解时长
- 设计套餐组合（如"买3件送1件"）提高客单价
- 检查是否大量低质量流量拉低了转化

## 主播状态管理

### 主播忘词/卡壳

**即时处理：**
- 通过耳麦快速提示关键词（不说完整话术，只说关键词如"价格"、"赠品"、"限量"）
- 如果主播完全卡住，场控从中控台发一条弹幕提示（如"今天的价格是多少呀？"引导主播自然接话）
- 递上话术卡片，让主播可以低头看一眼
- 如果持续超过30秒无法恢复，切换到互动环节（发福袋），给主播缓冲时间

### 主播情绪低落/状态差

**表现：** 声音低沉、缺乏激情、讲解敷衍、互动少

**即时处理：**
- 通过耳麦提醒主播注意状态（"流量还行，加油"、"这个品转化不错"）
- 切换到主播最擅长、最有激情的品来提振状态
- 如果是疲劳导致，安排一个5分钟的福袋互动环节，让主播可以坐着休息
- 场控主动承担更多互动工作（读弹幕、回复评论），减轻主播负担
- 如果状态持续差且影响转化，考虑提前结束直播（比硬撑着效果更好）

### 主播与弹幕冲突

**表现：** 主播被弹幕中的负面评论影响情绪，开始与观众争论

**即时处理：**
- 通过耳麦提醒主播"不要回应黑评，继续讲品"
- 场控在中控台设置弹幕过滤词，屏蔽攻击性词汇
- 切换话题/切品，转移主播注意力
- 如果弹幕有合理的售后/产品问题，场控主动在评论区回复解决，让主播不用分心

## 设备与技术故障

### 直播断流/黑屏

**这是最紧急的直播事故，必须在30秒内开始处理。**

**处理流程：**
1. **不要慌** — 场控第一时间安抚团队情绪
2. **判断断流原因：**
   - 网络问题 → 切换备用网络/4G热点，重新开播
   - 设备问题 → 切换备用手机/相机
   - 平台问题 → 检查是否有违规通知，联系平台客服
3. **重连期间：**
   - 如果有第二机位，先用备用画面顶上
   - 在粉丝群发通知"马上恢复，请稍等"
4. **恢复后：**
   - 主播第一时间做歉意+福利补偿话术（"刚才断了一会儿，给大家补一个福利"）
   - 立即发福袋/优惠券做留存
   - 不要纠结断流原因（复盘再查），优先恢复直播节奏

### 声音问题

| 故障 | 检查顺序 | 解决方案 |
|------|----------|----------|
| 无声 | 麦克风开关→电池→接收器→线缆 | 换备用麦，或用手机自带麦克风应急 |
| 杂音/回声 | 麦克风位置→音箱反馈→附近电子设备干扰 | 调整麦克风位置，关闭附近干扰源 |
| 声音忽大忽小 | 麦克风电量不足→距离变化→收音模式设置 | 换电池/提醒主播保持距离，检查收音设置 |

### 画面问题

| 故障 | 检查顺序 | 解决方案 |
|------|----------|----------|
| 画面模糊 | 镜头脏污→对焦设置→分辨率设置 | 擦镜头，检查对焦模式 |
| 画面卡顿 | 网络→设备性能→直播软件设置 | 降低分辨率/帧率，切换网络 |
| 灯光异常 | 灯泡损坏→色温设置→电源问题 | 换备用灯，调整色温到5500K |

## 突发舆情与黑粉应对

### 黑粉/竞对攻击

**判断标准：** 弹幕出现大量负面/攻击性评论，可能是竞对恶意行为。

**应对动作：**
1. 场控在中控台设置弹幕屏蔽词（攻击性词汇、竞品名称、负面关键词）
2. 场控或客服在弹幕区积极回复正面内容，稀释负面比例
3. 不要让主播看到/回应负面评论
4. 如果攻击量大，发福袋引导正常观众互动，稀释弹幕中负面比例
5. 记录攻击内容和时间，直播后向平台举报

### 产品质量问题被弹幕放大

**判断标准：** 有观众在弹幕反馈产品问题，引发大量跟风讨论。

**应对动作：**
- 如果是真实问题：场控快速确认问题是否属实，如属实提醒主播正面回应+给出解决方案
- 如果是误解：场控引导主播做补充说明/演示澄清
- 如果是恶意夸大：客服在评论区做专业回复，场控通过弹幕屏蔽词控制扩散
- 严重时切到下一个品，减少该品的曝光时间

## 后台操作异常

### 库存超卖

**表现：** 实际库存已售完但系统仍显示可购买，导致超卖退款。

**处理：**
- 立即在后台修改库存为0或下架该商品
- 通知主播"该品已售罄"并引导话术转为"福利已抢完"的正面表述
- 记录超卖单数，直播后统一做退款+补偿处理
- 复盘时分析原因（库存设置错误/未及时改库存）

### 价格设置错误

**表现：** 商品价格设置错误（如多打一个零或少打一个零）。

**处理：**
- 如果是卖贵了（实际价格高于预期）：立即修正价格，通知主播重新播报正确价格
- 如果是卖便宜了（实际价格低于预期）：
  - 评估损失大小，如果可控就当福利送
  - 如果损失大，立即下架该商品，做退款处理
  - 通知主播用话术承接（"这个品太火爆了/库存出了点问题，先下架了"）

### 优惠券/福袋发放错误

**处理：**
- 金额错误：立即停止当前优惠券/福袋，重新设置正确的发放
- 发放对象错误（如本应粉丝专属但发成了全员）：记录影响范围，复盘时评估损失
- 发放时机错误：做应急补救（如提前发了大额券，就提前进入逼单环节承接）

## 场控实时决策速查表

直播中场控需要快速决策的场景速查，按"看到什么→做什么"的格式整理：

| 看到的信号 | 说明什么 | 场控该做什么 |
|------------|----------|--------------|
| 在线人数连续3分钟上升 | 流量在涨，抓住机会 | 提示主播切到核心利润款承接流量 |
| 在线人数连续5分钟下降 | 流量在流失 | 切福利款+发福袋，拉回互动数据 |
| 商品点击率突然飙升 | 观众购买意愿增强 | 提示主播进入逼单话术，同步改库存制造紧迫感 |
| 商品点击率高但转化率低 | 想买但犹豫 | 提示主播做价格拆解/发限时优惠券/加强逼单 |
| 弹幕互动突然增多 | 内容触发了观众反应 | 让主播继续当前话题，顺势做互动转化 |
| 弹幕互动突然减少 | 内容失去吸引力 | 切品或提示主播换一个互动钩子 |
| 转化率连续3个品都低 | 不是单品问题而是整体问题 | 检查流量来源是否精准+主播状态是否正常 |
| UV价值低于行业基准 | 流量利用率低 | 增加利润款讲解时长/设计套餐提高客单价 |
| 在线人数高但互动率极低 | 进来了大量非精准流量 | 做互动引导（扣1/扣666），不要急着卖货 |
| 福袋参与率低 | 观众留存意愿低 | 检查福袋金额/门槛设置，适当提高吸引力 |
| 退款率实时上升 | 售后问题开始显现 | 记录退款品和原因，提示主播减少该品讲解 |
