## 场控的角色定义

场控是直播间的"现场指挥官"，核心价值在于**保障单场直播的顺利执行和实时优化**。

场控不是简单的"举牌员"或"后台操作员"，而是一个需要实时判断、快速反应的岗位。场控的工作边界覆盖直播间的每一个环节——从开播前的最后检查，到直播中的节奏把控、流量调度、数据监控，再到下播后的初步复盘。

**一句话定位：场控对单场直播的即时结果负责。**

## 运营的角色定义

运营是直播间的"操盘手"，核心价值在于**从策略层面驱动直播间的持续增长和盈利**。

运营的工作从单场直播扩展到周期性规划。运营不仅要懂执行，还要懂为什么这么执行——选品策略背后的逻辑、流量结构的搭建、人群标签的优化、投放节奏的把控，都是运营需要决策的事项。

**一句话定位：运营对直播间的长期增长和盈利负责。**

## 核心职责对比

| 维度 | 场控 | 运营 |
|------|------|------|
| **工作范围** | 单场直播的执行与实时优化 | 周期性直播规划与策略决策 |
| **时间视角** | 实时（分钟级反应） | 周期（天/周/月级规划） |
| **核心目标** | 保障单场直播GMV达标、流程顺畅 | 持续提升直播间整体GMV、ROI和增长趋势 |
| **选品排品** | 执行既定排品表，根据实时数据微调顺序 | 制定选品策略、排品逻辑、价格梯度设计 |
| **流量管理** | 监控实时流量变化，向运营反馈异常 | 规划流量结构（自然+付费比例）、投放策略 |
| **数据使用** | 实时看罗盘大屏，做即时调整 | 跨场次对比分析，做策略迭代 |
| **团队协作** | 与主播实时配合、控场节奏 | 统筹主播、场控、中控、客服等全链路 |
| **复盘深度** | 记录单场关键事件和数据 | 归因分析、策略优化方案、下场调整计划 |
| **决策权限** | 执行层决策（切品时机、催单节奏） | 策略层决策（预算分配、选品方向） |
| **考核指标** | 单场GMV达成率、流程零失误 | 周期GMV增长率、ROI、粉丝增长等 |
| **能力重心** | 执行力、反应速度、数据敏感度 | 策划力、分析力、决策力、统筹力 |

## 场控能力模型

### 基础能力（必须具备）

**1. 直播间操作能力**
- 熟练操作抖店后台：商品上架/下架、改价、改库存、上架序号调整
- 熟练操作直播中控台：福袋、优惠券发放、弹幕推送、商品讲解卡切换
- 熟练操作罗盘大屏：知道每个数据模块的位置和含义，能快速定位异常

**2. 排品执行能力**
- 理解排品逻辑（引流款→利润款→爆款→清仓款的节奏）
- 能根据主播状态和实时数据判断何时切品
- 知道每个品的卖点、价格机制、库存限制

**3. 实时数据监控能力**
- 能同时关注GMV、在线人数、转化率、平均停留时长等核心指标
- 能快速判断数据异常并定位可能原因
- 知道什么数据对应什么动作（如在线人数暴跌→检查流量来源→判断是否需要催播）

**4. 控场配合能力**
- 能与主播形成默契配合：何时递品、何时提示改话术、何时催单
- 能通过提词器/耳麦/手势等方式给主播传递信息
- 能控制直播节奏：快节奏逼单 vs 慢节奏种草的切换时机

**5. 应急处理能力**
- 设备故障（断流、黑屏、杂音）的快速处理
- 主播状态异常（忘词、情绪波动、身体不适）的补救
- 黑粉攻击、差评刷屏的应对
- 库存超卖、价格错误等后台异常的紧急处理

### 进阶能力（优秀场控具备）

**6. 数据归因意识**
- 不只看"数据好不好"，还能初步判断"为什么不好"
- 能在复盘中提供有价值的现场观察（哪个时段流量掉了、哪个品转化好）

**7. 流量感知能力**
- 对自然流量波动有直觉判断（开播冲量、平销期、返场高峰的规律）
- 能配合运营做简单的流量调度（如引导关注、发福袋拉互动）

**8. 话术优化建议**
- 能根据转化数据判断哪些话术有效、哪些需要调整
- 能在复盘时给主播提供话术改进建议

## 运营能力模型

### 运营在场控能力基础上的增量

**1. 策略规划能力**
- 能独立制定月度/季度直播计划（频次、时长、目标GMV分解）
- 能根据店铺整体经营节奏安排直播节奏（大促节点 vs 日常）
- 能做竞品分析并提取可借鉴策略

**2. 选品与商品策略能力**
- 能独立做选品决策（不只是排品顺序，而是选什么品、为什么选）
- 能设计价格梯度机制（引流款定价、利润款定价、套餐组合设计）
- 能根据数据反馈调整选品策略（哪些品类持续投放、哪些该淘汰）

**3. 流量策略能力**
- 能制定自然流量和付费流量的结构比例
- 能与千川投放师协同制定投放策略（人群定向、出价策略、素材策略）
- 能分析流量结构（推荐feed、直播广场、关注tab、付费流量各占多少）并优化

**4. 深度数据分析能力**
- 能做跨场次、跨周期的数据对比分析
- 能做归因分析（GMV涨/跌的核心原因是什么）
- 能从数据中发现增长机会（某个品类潜力大、某个时段效率高）
- 能用数据说服团队支持策略调整

**5. 团队统筹能力**
- 能管理场控、中控、客服等执行岗位
- 能与主播建立有效的沟通机制（话术指导、复盘反馈）
- 能跨部门协作（与供应链对接库存、与设计对接素材、与投放对接预算）

**6. 财务意识**
- 能做直播ROI测算（含投放成本、商品成本、人力成本）
- 能做利润分析（不是只看GMV，还要看实付、退款、净利）
- 能做预算规划（投放预算分配、货品成本控制）

## 晋升标准：场控→运营

### 硬性指标参考

| 考核维度 | 达标标准 | 优秀标准 |
|----------|----------|----------|
| 场控经验 | 独立控场≥100场 | 独立控场≥200场，含大促场次 |
| 单场GMV把控 | 连续30场达成运营设定目标 | 连续30场超额达成≥10% |
| 应急处理 | 能独立处理≥5种突发情况 | 处理过程被记录为团队SOP案例 |
| 复盘能力 | 能独立输出结构化复盘报告 | 复盘报告能提出被采纳的优化建议 |
| 数据分析 | 能准确解读罗盘大屏所有核心指标 | 能做跨场次数据对比并提出洞察 |
| 排品执行 | 能根据实时数据自主调整排品节奏 | 能参与排品策略制定并提出有效建议 |

### 软性能力评估

- **主动性**：不等待指令，主动发现问题并提出解决方案
- **学习力**：主动学习运营知识（投放基础、选品逻辑、数据分析方法）
- **沟通力**：能与主播、运营、投放师等多角色有效沟通
- **决策力**：在模糊信息下能做出合理判断并承担结果
- **大局观**：思考问题从"单场"上升到"周期性"，从"执行"上升到"策略"

### 晋升评估流程（参考）

1. **场控自评** — 对照能力模型自评，找出差距
2. **运营带教评价** — 由直属运营评价实际工作中的表现
3. **模拟考核** — 给一个历史直播数据，要求做完整复盘+优化方案（考核分析能力和策略思维）
4. **试岗期** — 在运营带领下，试做2-4周的运营工作（选品建议、投放策略参与、复盘主导）
5. **综合评定** — 结合硬性指标、软性能力、模拟考核和试岗表现综合判断

## 晋升后运营需要新增的工作

从场控晋升为运营后，工作重心从"执行"转向"策略+统筹"，但并不意味着完全脱离现场。新晋运营需要逐步承担以下新增职责：

### 第一阶段（晋升1-3个月）：从执行到策略的过渡

| 新增工作 | 具体内容 | 与场控时期的区别 |
|----------|----------|------------------|
| 参与选品决策 | 不再只是执行排品表，而是参与选品讨论，提出选品建议 | 场控只管"按表执行"，运营要懂"为什么这么选" |
| 主导复盘会议 | 从"提供现场观察"升级为"主持复盘、输出优化方案" | 场控是复盘参与者，运营是复盘主导者 |
| 千川投放协同 | 与投放师沟通投放节奏和人群策略 | 场控只看投放结果，运营要参与投放决策 |
| 周度数据报告 | 做跨场次数据对比，输出周度直播经营报告 | 场控关注单场数据，运营关注趋势和归因 |

### 第二阶段（晋升3-6个月）：独立操盘

| 新增工作 | 具体内容 |
|----------|----------|
| 独立制定直播计划 | 月度直播频次、时长、目标GMV分解 |
| 独立选品排品 | 从选品到排品全链路负责 |
| 流量结构优化 | 分析自然/付费流量比例，制定优化策略 |
| 主播培养 | 给主播做话术培训、数据反馈、状态管理 |
| 预算管理 | 投放预算分配、货品成本控制、ROI测算 |

### 第三阶段（6个月以上）：团队管理

| 新增工作 | 具体内容 |
|----------|----------|
| 带教新场控 | 将自己的场控经验沉淀为SOP，培训新人 |
| 多直播间统筹 | 如果团队有多个直播间，负责资源分配和优先级排序 |
| 经营策略 | 结合店铺整体经营（货架+直播）做直播策略定位 |
| 向上汇报 | 向品牌方/老板汇报直播经营状况和增长计划 |

### 关键认知转变

从场控到运营，最核心的转变不是"多做了几件事"，而是**思考维度的升级**：

- 从"这场直播怎么执行好" → "这个周期的直播怎么持续增长"
- 从"数据出问题了怎么办" → "数据为什么会出问题，怎么从源头预防"
- 从"听指令做事" → "发现问题、定义问题、解决问题"
- 从"对单场结果负责" → "对经营趋势负责"
