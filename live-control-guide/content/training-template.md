## 文档生成格式说明

当用户要求生成培训文档时：

1. **先确认培训对象** — 新场控/进阶场控/运营
2. **选择对应模板**
3. **读取相关知识文件** — 根据模板章节标注的内容来源读取
4. **填充内容** — 将知识文件中的内容按模板结构组织
5. **选择输出格式：**
   - Word文档 → 使用 docx 技能
   - PDF文档 → 使用 pdf 技能
   - 对话内输出 → 直接用 Markdown 格式输出
6. **告知用户文件路径** — 生成文件后返回路径供用户下载

## 快速Q&A参考卡（可选输出）

当用户只需要快速参考卡时，可以输出精简版：

```
# 场控快速参考卡

## 直播前30分钟必做
- [ ] 测试画面/声音/网络
- [ ] 确认商品上架顺序正确
- [ ] 确认优惠券/福袋已设置
- [ ] 与主播对一遍核心品话术
- [ ] 确认备用设备就位

## 直播中关键决策
| 信号 | 动作 |
|------|------|
| 在线人数3分钟连涨 | 切利润款承接 |
| 在线人数5分钟连跌 | 切福利款+发福袋 |
| 点击率高但转化率低 | 提示逼单+发限时券 |
| 弹幕互动突然变少 | 切品或换互动钩子 |

## 应急处理优先级
1. 断流 → 30秒内切换备用方案
2. 库存超卖 → 立即改库存为0
3. 价格错误 → 立即下架该品
4. 主播卡壳 → 耳麦提示关键词
5. 黑粉刷屏 → 设置弹幕屏蔽词

## 下播后必做
- [ ] 记录最终GMV和核心指标
- [ ] 记录关键事件（流量突变/切品决策/异常情况）
- [ ] 快速复盘（30分钟内）
- [ ] 确认下场时间和调整方向
```
