## 复盘的核心目的

复盘不是为了"写报告交差"，而是为了回答三个问题：

1. **这场直播的结果如何？** — 用数据说话，不凭感觉
2. **为什么是这个结果？** — 找到数据和动作之间的因果关系
3. **下场怎么做得更好？** — 输出可执行的具体优化动作

一场不复盘的直播，等于白做。直播电商的本质是**数据驱动迭代**，每一场的数据都在告诉你下一步该怎么做。

## 复盘流程框架

### T+0（下播后30分钟内）— 快速复盘

场控主导，团队参与（主播+中控+运营），快速对齐本场概况：

- [ ] 记录最终GMV和核心指标（在线人数峰值/均值、转化率、UV价值）
- [ ] 回顾关键事件（什么时候流量涨了/跌了、哪个品转化最好/最差、有无突发情况）
- [ ] 快速识别1-3个最突出的问题（不要贪多，抓主要矛盾）
- [ ] 确认下场直播的时间和调整方向

### T+1（第二天）— 深度复盘

运营主导，场控提供现场视角，做深度分析：

- [ ] 导出完整直播数据（罗盘大屏全量数据+千川投放数据+抖店后台数据）
- [ ] 做分时段数据拆解（每15分钟/每30分钟的GMV、在线人数、转化率变化曲线）
- [ ] 做商品维度拆解（每个品的讲解时长、点击率、转化率、GMV贡献占比）
- [ ] 做流量维度拆解（各渠道流量占比、各渠道转化效率）
- [ ] 归因分析（GMV涨/跌的核心原因）
- [ ] 输出优化方案（下场具体调整什么）
- [ ] 同步给团队，确保每个人知道下场自己的调整项

### T+7（一周后）— 周期复盘

运营主导，做跨场次对比分析：

- [ ] 本周所有场次的GMV趋势对比
- [ ] 周内各场次的转化率/UV价值/在线人数对比
- [ ] 选品效果横向对比（哪些品持续好/差）
- [ ] 流量结构周度变化（自然/付费比例变化趋势）
- [ ] 输出周度优化策略调整

## 数据复盘维度

### 核心指标体系

| 指标 | 定义 | 健康判断参考 | 告警信号 |
|------|------|-------------|----------|
| GMV | 直播间成交总额 | 对比目标达成率 | 达成率<80%需重点分析 |
| 在线人数峰值 | 直播期间最高同时在线 | 对比同时段历史水平 | 低于历史均值30%以上 |
| 平均在线人数 | 整场直播平均在线 | 对比同品类行业水平 | 低于行业基准50% |
| 平均停留时长 | 观众平均停留时间 | 服装类>90秒/美妆>60秒/食品>45秒 | 低于品类基准需排查内容质量 |
| 商品点击率 | 点击商品人数/观看人数 | 5%-15%为正常区间 | <3%说明选品或话术有问题 |
| 转化率 | 成交人数/观看人数 | 服装2-5%/美妆3-8%/食品5-15% | 低于品类基准需排查价格和话术 |
| UV价值 | GMV/在线人数 | 因品类差异大，看自身趋势 | 连续3场下降需预警 |
| 互动率 | 互动人数/观看人数 | >5%为健康 | <2%说明内容缺乏互动引导 |
| 新增粉丝数 | 直播期间新增关注数 | 对比同场次历史 | 连续下降需检查粉丝引导话术 |
| 退款率 | 退款订单/总订单 | <10%为健康 | >15%需排查产品质量和话术误导 |

### 分时段数据拆解

分时段拆解是发现问题的核心方法。将一场直播按15分钟或30分钟切分，看每个时间段的数据变化：

**看什么：**
- GMV曲线的峰值和谷值分别出现在什么时段
- 在线人数曲线和GMV曲线是否同步（如果人数涨但GMV不涨，说明流量不精准或话术不到位）
- 转化率在哪些时段突然飙升或骤降
- 流量来源在不同时段的变化（付费流量占比是否合理）

**分析逻辑：**
- 峰值时段做了什么对的事 → 沉淀为SOP，下场重复
- 谷值时段做了什么错的事 → 找原因，下场避免
- 数据突变时段对应了什么关键事件（切品、发券、断流等）

### 商品维度拆解

| 分析维度 | 看什么 | 判断 |
|----------|--------|------|
| GMV贡献占比 | 每个品贡献了多少GMV | 头部品贡献>40%说明排品依赖性强，需培养更多利润款 |
| 点击率 | 每个品的点击人数占比 | 点击率<3%的品考虑淘汰或调整话术 |
| 转化率 | 每个品的成交转化率 | 转化率低于品类均值的品需分析原因 |
| 讲解时长效率 | GMV/讲解时长 | 效率最低的品下次减少讲解时间或调整排品位置 |
| 退款率 | 每个品的退款比例 | 退款率>15%的品需排查质量/话术/价格合理性 |

## 关键事件复盘

关键事件复盘是场控最有价值的贡献——因为你是在现场的人，很多数据看不到的东西只有你知道。

### 需要记录的关键事件

| 事件类型 | 记录内容 | 为什么重要 |
|----------|----------|------------|
| 流量突变点 | 什么时间在线人数突然涨/跌，当时在做什么 | 找到影响流量的关键动作 |
| 切品决策点 | 什么时间切了什么品，为什么切 | 评估切品决策是否正确 |
| 话术调整点 | 主播在哪个环节做了话术调整，效果如何 | 沉淀有效话术模板 |
| 突发情况 | 断流/设备故障/黑粉攻击等，处理过程和耗时 | 评估应急处理效率 |
| 优惠券/福袋发放 | 什么时间发了什么力度的福利，效果如何 | 优化福利发放节奏 |
| 主播状态变化 | 主播在什么时段状态好/差，对应的数据表现 | 优化排品节奏和主播休息安排 |
| 弹幕热点 | 弹幕中观众关注最多的问题/话题 | 洞察消费者需求和痛点 |

## 归因分析方法

### GMV归因分析框架

GMV = 流量 × 转化率 × 客单价

当GMV不达标时，先拆解是哪个环节出了问题：

**第一步：拆解三大变量**
- 流量（总观看人数）够不够？
- 转化率（看的人中买了多少）达标吗？
- 客单价（每单平均多少钱）合理吗？

**第二步：深挖异常变量**

如果流量不够：
- 是哪个渠道的流量少了？（推荐feed/直播广场/关注tab/付费）
- 是时段问题还是内容问题？
- 对比历史同时段数据，判断是否异常

如果转化率低：
- 是所有品都低还是个别品低？
- 是点击率低（不想看）还是成交转化率低（看了不买）？
- 话术、价格、流量精准度哪个环节有问题？

如果客单价低：
- 是引流款占比过高？
- 是利润款转化差？
- 套餐/组合设计是否合理？

**第三步：定位根因**

将数据问题对应到具体动作：
- 流量少 → 可能是预热不足/投放不够/内容互动数据差导致推荐减少
- 转化低 → 可能是话术不到位/价格机制不合理/流量不精准
- 客单价低 → 可能是排品策略问题/利润款话术不够有吸引力

### 场控视角的归因补充

场控在归因分析中能提供的独特价值：
- 数据无法反映的现场情况（主播当时的状态、话术执行偏差）
- 切品决策的实时逻辑（为什么在那个时间点切品）
- 弹幕中的消费者真实反馈
- 竞对动态（同时段竞对在做什么）

## 优化方案输出

### 优化方案结构

复盘的最终产出不是"发现了什么问题"，而是"下场怎么改"。优化方案应包含：

| 维度 | 发现的问题 | 根因分析 | 下场优化动作 | 责任人 |
|------|-----------|----------|--------------|--------|
| 流量 | 开播30分钟在线人数仅xxx | 预热短视频未按时发布 | 下场提前24小时发布预热视频+开播加大投放 | 运营 |
| 转化 | 核心品A转化率仅x% | 主播价格讲解不清 | 优化价格话术模板+开播前过堂 | 场控+主播 |
| 排品 | 引流款占比过高拉低UV价值 | 排品表中引流款3个太多 | 下场引流款减至2个，增加1个利润款 | 运营 |
| 流量结构 | 付费流量占比60%偏高 | 自然流量获取不足 | 优化内容互动数据拉自然推荐+调整投放定向 | 运营+投放 |

### 优化方案输出原则

- 每场复盘聚焦**3-5个核心优化项**，不要贪多
- 每个优化项必须有**明确的下场动作**（不是"提高转化率"，而是"核心品讲解时增加价格拆解环节"）
- 每个优化项必须有**责任人**和**验收标准**
- 优化动作需在场控记录表中跟踪，下场复盘时检查是否执行

## 场控复盘 vs 运营复盘

| 维度 | 场控复盘 | 运营复盘 |
|------|----------|----------|
| 视角 | 现场执行视角 | 策略分析视角 |
| 核心输出 | 现场关键事件记录+执行层面的问题发现 | 数据归因分析+策略优化方案 |
| 时间范围 | 聚焦单场 | 单场+跨场次对比 |
| 关注重点 | "执行得怎么样"（切品时机对不对、应急处理快不快） | "策略对不对"（选品对不对、流量结构合不合理） |
| 优化建议方向 | 执行层面改进（话术配合、切品决策、应急流程） | 策略层面调整（选品方向、排品逻辑、投放策略） |
| 复盘报告格式 | 简洁的事件记录+问题清单 | 结构化的数据分析+优化方案表 |
