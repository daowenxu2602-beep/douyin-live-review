## 直播团队角色分工

抖音电商直播间的标准团队配置及职责边界：

| 角色 | 核心职责 | 工作时间范围 | 考核指标 |
|------|----------|-------------|----------|
| 主播 | 镜头前讲解、互动、成交转化 | 直播期间+话术准备 | GMV达成、转化率、粉丝增长 |
| 场控 | 现场指挥、节奏把控、实时优化、应急处理 | 直播前1h+直播中+下播后30min | 单场GMV达成率、流程零失误 |
| 运营 | 策略规划、选品排品、流量策略、深度复盘 | 全周期（周/月级） | 周期GMV增长率、ROI |
| 中控 | 后台操作（上架/改价/改库存/发券/福袋） | 直播期间 | 操作零失误、响应速度 |
| 投放师 | 千川投放策略、出价、定向、素材 | 直播前+直播中+复盘 | 投放ROI、获客成本 |
| 客服 | 弹幕回复、售后处理、退换货 | 直播期间+售后时段 | 响应速度、好评率、退款率 |

**小团队情况（1人兼多岗）：**
- 主播兼运营：主播自己策划和选品，需要场控更多承担运营的现场职能
- 场控兼中控：场控同时负责后台操作，需要更高效的时间管理
- 运营兼投放：运营自己做千川投放，场控需要更多关注投放数据反馈

## 场控与主播的协作

### 协作原则

场控和主播是直播间配合最紧密的两个人，协作质量直接决定直播效果。

**核心原则：场控是主播的"外脑"和"第三只眼"。**

主播在镜头前需要全神贯注于表达和互动，很难同时关注数据变化、后台操作和全局节奏。场控的角色就是做主播看不到的事，并及时传递关键信息。

### 日常协作机制

**直播前：**
- 一起过排品表，确认每个品的讲解重点和价格机制
- 对一遍话术，特别是核心利润款的话术
- 确认关键节奏点（什么时间发福利、什么时间做爆款返场）
- 约定沟通暗号（耳麦提示方式、手势含义）

**直播中：**
- 场控通过耳麦实时传递关键信息（在线人数变化、转化率反馈、切品建议）
- 场控控制递品节奏（什么时间递什么品、什么道具）
- 场控通过中控台配合（发券时机、改库存时机、弹幕推送）
- 主播根据场控提示调整话术和节奏

**直播后：**
- 一起做快速复盘，对齐本场概况
- 场控反馈主播状态和话术效果
- 主播反馈场控配合的顺畅度和改进建议

### 沟通暗号设计

建议团队约定一套简洁的沟通暗号，避免在直播中说太多话：

| 暗号 | 含义 | 使用场景 |
|------|------|----------|
| 耳麦说"切" | 该切到下一个品了 | 当前品讲解时间已够或转化持续低迷 |
| 耳麦说"逼单" | 进入逼单环节 | 在线人数好/点击率高但转化率低 |
| 耳麦说"福利" | 发福利救场 | 在线人数下跌需拉升互动 |
| 耳麦说"价格" | 再讲一遍价格 | 价格机制没讲清/弹幕有人问价格 |
| 耳麦说"库存X" | 当前库存还剩X件 | 用于制造紧迫感话术 |
| 耳麦说"在线X" | 当前在线X人 | 让主播感知流量变化 |
| 弹幕推送数字 | 提示关键数据 | 如推送"今日限时特价"提示主播报价格 |

## 场控与运营的协作

### 协作原则

**核心原则：运营是场控的"策略大脑"，场控是运营的"现场眼睛"。**

运营制定策略和目标，场控负责执行并在现场做出实时调整。场控的现场观察和数据反馈是运营做策略迭代的核心输入。

### 日常协作机制

**直播前：**
- 运营向场控同步本场策略要点（目标GMV、重点品、特殊活动、流量预期）
- 场控向运营反馈排品表的执行可行性（库存是否充足、品是否有特殊机制需要注意）
- 确认投放计划和预算分配

**直播中：**
- 场控定期向运营汇报关键数据变化（每30分钟或关键节点）
- 出现重大异常时第一时间通知运营（流量暴跌、转化异常、设备故障）
- 运营在场时场控做执行层决策，运营不在场时场控做更多自主判断

**直播后：**
- 场控提交现场记录（关键事件、切品决策、异常情况）
- 运营基于场控记录+后台数据做深度复盘
- 运营输出优化方案，场控确认执行层面的可行性

### 信息同步规范

场控向运营汇报时，使用结构化格式：

```
【时段汇报】XX:XX-XX:XX
- GMV: xxx（目标达成率xx%）
- 在线人数: 峰值xxx/当前xxx
- 转化率: xx%
- 关键事件: （简述发生的重要事项）
- 需要运营决策: （如有，列出需要运营决定的事项）
```

## 场控与中控的协作

### 协作原则

**核心原则：场控是"指挥"，中控是"操作手"。**

场控决定"做什么"，中控负责"怎么做"（具体后台操作）。如果场控同时兼任中控，需要更注重操作效率。

### 分工边界

| 操作 | 场控决策 | 中控执行 |
|------|----------|----------|
| 切品 | 判断何时切、切到哪个品 | 在中控台调整商品讲解顺序 |
| 改库存 | 判断何时改、改成多少 | 在后台修改库存数量 |
| 发优惠券 | 判断何时发、发什么券 | 在后台设置并发放优惠券 |
| 发福袋 | 判断何时发、金额多少 | 在后台设置并发放福袋 |
| 弹幕推送 | 判断推什么内容 | 在中控台输入并发送弹幕 |
| 下架商品 | 判断何时下架 | 在后台操作下架 |

### 协作要点

- 场控给中控的指令要**简洁明确**（"3号品改库存50"、"发10元券100张"）
- 中控执行后需**口头确认**（"改好了"、"发好了"）
- 关键操作（改价、改库存）建议**双人确认**避免失误
- 中控在空闲时段关注弹幕，将重要反馈传达给场控

## 场控与投放师的协作

### 协作原则

**核心原则：场控提供现场数据，投放师做投放决策，双方实时协同调整。**

### 协作要点

**直播前：**
- 投放师向场控同步投放计划（预算、出价策略、定向人群、素材）
- 场控向投放师同步排品策略（哪个时段推哪个品，方便投放师做素材匹配）

**直播中：**
- 场控向投放师反馈实时数据（在线人数、转化率、流量来源变化）
- 投放师向场控反馈投放数据（消耗速度、ROI、点击率）
- 当流量不足时，场控向投放师提出加投需求
- 当流量不精准时，场控向投放师反馈需调整定向

**直播后：**
- 投放师提供完整投放数据
- 场控提供现场转化数据
- 双方协同分析流量质量和投放效率

## 跨岗位沟通规范

### 沟通渠道

| 场景 | 渠道 | 注意事项 |
|------|------|----------|
| 直播中实时沟通 | 耳麦/对讲机 | 简洁、用暗号、不打断主播 |
| 直播中数据同步 | 微信群/工作群 | 定时汇报+异常即时报 |
| 紧急情况 | 口头直接沟通 | 场控有权暂停任何流程处理紧急情况 |
| 复盘讨论 | 线下会议/视频会议 | 所有人参与，场控提供现场视角 |
| 日常非紧急事项 | 微信群异步沟通 | 不在直播中发非紧急消息干扰场控 |

### 沟通禁忌

- 直播中不在大群里发无关消息，避免干扰场控和运营
- 不在主播能看到的群/弹幕中讨论负面信息
- 不在直播中争论决策（先执行，复盘时再讨论对错）
- 不在客户/品牌方面前暴露团队内部分歧

## 常见协作冲突与解决

| 冲突场景 | 原因 | 解决方式 |
|----------|------|----------|
| 场控和主播对切品时机意见不一致 | 双方对数据和节奏判断不同 | 直播中以场控决策为准（场控看全局数据），复盘时讨论 |
| 运营责怪场控没按排品表执行 | 排品表与现场情况不符 | 场控有权根据实时数据调整排品，但需在复盘中说明调整原因 |
| 中控操作失误导致超卖/错价 | 指令不清晰或操作匆忙 | 建立双人确认机制，关键操作场控复核 |
| 投放师觉得流量不好是内容问题，场控觉得是投放问题 | 归因分歧 | 用数据说话——看流量来源各渠道的转化率对比 |
| 主播觉得场控管太多，场控觉得主播不听指挥 | 职责边界不清 | 开播前明确分工和沟通规则，复盘时共同复盘协作效果 |
| 运营策略脱离实际，场控执行困难 | 运营不了解现场限制 | 场控在策略讨论阶段就参与，提出执行可行性意见 |

### 冲突解决原则

1. **直播中以场控为现场最高决策权** — 现场情况千变万化，不能等讨论完再行动
2. **复盘时对事不对人** — 讨论决策是否正确，不讨论谁对谁错
3. **用数据说话** — 意见分歧时看数据，不凭感觉
4. **建立SOP减少争议** — 常见场景形成标准操作流程，减少临时决策的分歧
